## 1.2 产品定位

vue-admin-system-pro 是基于 vue-vben-admin 5.0 定制的中后台管理系统模板，旨在提供开箱即用的企业级前端解决方案。核心定位：

- **通用性**：适用于各类企业管理系统（ERP、OA、CRM、B2B 等）
- **规范性**：遵循前端工程化最佳实践，代码结构清晰可维护
- **扩展性**：基于 Monorepo 架构，便于多应用拆分与复用

## 1.5 核心功能路径图

### 用户登录流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Login as 登录页
    participant Auth as AuthStore
    participant Access as AccessStore
    participant API as 登录API

    User->>Login: 输入用户名/密码
    Login->>Auth: authLogin(params)
    Auth->>API: loginApi(params)
    API-->>Auth: 返回 accessToken
    Auth->>Access: setAccessToken(token)
    Auth->>Auth: fetchUserInfo()
    Auth->>Auth: getAccessCodes()
    Auth->>Login: 登录成功，跳转首页
```

### 页面访问权限流程

```mermaid
sequenceDiagram
    participant Router as Vue Router
    participant Guard as 路由守卫
    participant Auth as AuthStore
    participant Access as AccessStore
    participant Gen as generateAccess

    Router->>Guard: 访问 /xxx
    Guard->>Access: 检查 accessToken
    Access-->>Guard: 无 Token
    Guard->>Router: 重定向到登录页
    Access-->>Guard: 有 Token
    Guard->>Access: 检查 isAccessChecked
    Access-->>Guard: 未生成路由
    Guard->>Auth: fetchUserInfo()
    Auth-->>Guard: 用户信息 + roles
    Guard->>Gen: generateAccess(roles)
    Gen-->>Guard: 动态路由 + 菜单
    Guard->>Access: setAccessMenus/Routes
    Guard->>Router: 放行
```

## 1.7 关键入口文件

## 1.8 关键配置

### 环境配置

```bash
# .env (通用配置)
VITE_APP_TITLE='Admin System'
VITE_APP_NAMESPACE=admin-system-pro
VITE_APP_STORE_SECURE_KEY=please-replace-me-with-your-own-key

# .env.development
VITE_PORT=5777
VITE_GLOB_API_URL=/api
VITE_PROJECT_API_URL=http://localhost:8081
VITE_NITRO_MOCK=true

# .env.production
VITE_GLOB_API_URL=https://mock-napi.vben.pro/api
VITE_ROUTER_HISTORY=hash
VITE_COMPRESS=none
```
