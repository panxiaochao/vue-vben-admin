## 3.4 共享包说明

### @vben/core 包

| 包名                     | 说明             | 核心导出                   |
| ------------------------ | ---------------- | -------------------------- |
| `@vben-core/design`      | 设计系统         | 主题、颜色、字体           |
| `@vben-core/menu-ui`     | 菜单组件         | 菜单渲染逻辑               |
| `@vben-core/shadcn-ui`   | Shadcn 风格组件  | Button, Dialog 等          |
| `@vben-core/composables` | 核心 Composables | useVbenForm, useVbenDrawer |
| `@vben-core/preferences` | 偏好设置         | 用户配置管理               |

### @vben/effects 包

| 包名                | 说明           | 核心功能                      |
| ------------------- | -------------- | ----------------------------- |
| `@vben/access`      | 权限控制       | 动态路由生成、权限指令        |
| `@vben/common-ui`   | 通用 UI        | Modal, Drawer, Page 等        |
| `@vben/hooks`       | 生命周期 Hooks | useBeforeRender, useWatermark |
| `@vben/layouts`     | 布局组件       | BasicLayout, AuthLayout       |
| `@vben/locales`     | 国际化         | setupI18n, $t                 |
| `@vben/plugins`     | 插件集成       | ECharts, VxeTable, Motion     |
| `@vben/request`     | HTTP 请求      | RequestClient, 拦截器         |
| `@vben/preferences` | 偏好设置       | 用户配置持久化                |

### @vben 共享包

| 包名 | 说明 |
| --- | --- |
| `@vben/stores` | Pinia Store (useAccessStore, useUserStore, useTabbarStore) |
| `@vben/utils` | 工具函数 (resetStaticRoutes, openWindow) |
| `@vben/types` | 类型定义 (UserInfo, RouteRecordRaw) |
| `@vben/constants` | 常量 (LOGIN_PATH) |
| `@vben/styles` | 全局样式、Ant Design 样式 |
| `@vben/icons` | 图标组件 |

## 3.7 环境变量配置

### 开发环境 (.env.development)

```bash
VITE_PORT=5777
VITE_BASE=/
VITE_GLOB_API_URL=/api
VITE_PROJECT_API_URL=http://localhost:8081
VITE_NITRO_MOCK=true
VITE_DEVTOOLS=false
```
