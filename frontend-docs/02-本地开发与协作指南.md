# 02 - 本地开发与协作指南

## 2.1 环境要求

| 工具 | 版本要求 | 说明 |
| --- | --- | --- |
| Node.js | ^20.19.0 \|\| ^22.18.0 \|\| ^24.0.0 | 推荐使用 nvm 管理多版本 |
| pnpm | >=10.0.0 | **强制使用**，根目录 preinstall 强制检查 |

## 2.2 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/panxiaochao/vue-admin-system-pro.git

# 2. 进入目录
cd vue-admin-system-pro

# 3. 安装依赖 (自动触发 preinstall 检查)
pnpm install

# 4. 启动开发服务器
pnpm dev:system-admin

# 5. 访问 http://localhost:5777
```

## 2.3 包管理规范

### 强制使用 pnpm

根目录 `.npmrc` 和 `preinstall` 脚本禁止其他包管理器：

```bash
# .npmrc
shamefully-hoist=true
auto-install-peers=true
```

```json
// package.json
{
  "preinstall": "npx only-allow pnpm"
}
```

### 工作区协议

- **本地包引用**：`workspace:*` (如 `@vben/common-ui: workspace:*`)
- **目录别名**：`#/` 指向 `apps/vue-admin-system-pro/src/`

```json
// apps/vue-admin-system-pro/package.json
{
  "imports": {
    "#/*": "./src/*"
  }
}
```

### Catalog 模式

依赖版本集中在 `pnpm-workspace.yaml` 的 `catalog:` 块管理，所有包共享相同版本：

```yaml
# pnpm-workspace.yaml
catalog:
  vue: ^3.5.32
  vite: ^8.0.8
  pinia: ^3.0.4
```

## 2.4 Git 工作流

### 分支命名规范

```bash
feat/xxx          # 新功能
fix/xxx           # Bug 修复
docs/xxx          # 文档更新
style/xxx         # 代码格式（不影响功能）
perf/xxx          # 性能优化
refactor/xxx      # 重构
test/xxx          # 测试相关
chore/xxx         # 构建/工具变动
```

### 提交信息规范

遵循 Angular Convention (通过 commitlint 校验)：

| 类型     | 说明                   |
| -------- | ---------------------- |
| feat     | 新功能                 |
| fix      | Bug 修复               |
| style    | 代码格式（不影响运行） |
| perf     | 性能优化               |
| refactor | 重构                   |
| revert   | 回滚                   |
| test     | 测试相关               |
| docs     | 文档/笔记              |
| chore    | 依赖更新/脚手架配置    |
| ci       | 持续集成               |
| types    | 类型定义修改           |

提交示例：

```bash
feat(auth): add login expired modal handling
fix(system): correct role permission check logic
chore(deps): update ant-design-vue to 4.2.6
```

### 交互式提交

```bash
pnpm commit   # 使用 czg 交互式提交
```

## 2.5 代码质量工具链

### Lint/Format 工具

| 工具           | 用途           | 配置                   |
| -------------- | -------------- | ---------------------- |
| **oxfmt**      | 主格式化工具   | `oxfmt.config.ts`      |
| **oxlint**     | 主代码检查     | `oxlint.config.ts`     |
| **eslint**     | JS/TS/Vue 检查 | `eslint.config.mjs`    |
| **stylelint**  | 样式检查       | `stylelint.config.mjs` |
| **commitlint** | 提交信息规范   | `.commitlintrc.js`     |
| **cspell**     | 拼写检查       | `cspell.json`          |

### 命令速查

```bash
# 代码检查
pnpm lint              # 运行所有 lint
pnpm format            # 代码格式化
pnpm check             # 全量检查 (type + circular + dep + cspell)
pnpm check:type        # 仅类型检查
pnpm check:circular    # 循环依赖检查
pnpm check:dep         # 依赖检查
pnpm check:cspell      # 拼写检查
```

### Git Hooks (lefthook)

提交前自动触发检查，提交时验证 commit message：

```yaml
# lefthook.yml
pre-commit:
  parallel: true
  commands:
    lint-vue:
      run: pnpm oxfmt {staged_files} && pnpm oxlint --fix {staged_files} && pnpm eslint --cache --fix {staged_files} && pnpm stylelint --fix {staged_files}
      glob: '*.vue'
    lint-js:
      run: pnpm oxfmt {staged_files} && pnpm oxlint --fix {staged_files} && pnpm eslint --cache --fix {staged_files}
      glob: '*.{js,jsx,ts,tsx}'

commit-msg:
  commands:
    commitlint:
      run: pnpm exec commitlint --edit $1
```

## 2.7 环境变量指南

### 环境文件优先级

```
.env.*.local (最高)
.env.*.local

.env (普遍)

```

### 关键环境变量

| 变量 | 说明 | 示例值 |
| --- | --- | --- |

| `VITE_ROUTER_HISTORY` | Router 模式 | `hash/web` |

## 2.9 开发约定

### 路径别名

| 别名      | 指向                                     |
| --------- | ---------------------------------------- |
| `#/`      | `apps/vue-admin-system-pro/src/`         |
| `@vben/*` | `packages/@vben/*` 或 `packages/@core/*` |
| `@`       | `packages/` (部分场景)                   |

### 添加新页面

1. 创建组件：`src/views/{module}/{page}/index.vue`
2. 添加路由：`src/router/routes/modules/{module}.ts`
3. 国际化：添加到 `src/locales/langs/{zh-CN|en-US}/`

### CRUD 页面模式

参考 `src/views/system/role/`：

```
src/views/system/role/
├── data.ts           # 表格列和表单 Schema 定义
├── list.vue          # 列表页面
└── modules/
    └── form.vue      # 表单抽屉组件
```
