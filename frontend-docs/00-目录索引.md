## 架构总览图

```mermaid
graph TB
    subgraph "前端架构"
        UI[用户界面层<br/>Vue 3 + Ant Design Vue]
        Router[路由层<br/>Vue Router 5]
        Store[状态层<br/>Pinia 3]
        API[接口层<br/>Axios + RequestClient]
    end

    subgraph "构建与工具"
        Build[Vite 8<br/>tsdown]
        Lint[oxlint + eslint<br/>oxfmt + prettier]
        Test[Vitest + Playwright]
    end

    subgraph "Monorepo 管理"
        Turbo[TURBO 2<br/>pnpm workspaces]
    end

    UI --> Router
    Router --> Store
    UI --> Store
    Store --> API
    API --> Backend[后端服务]
```
